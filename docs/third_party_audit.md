# Third-party and frontend asset audit

Audit of the installed backend environment and frontend lockfile on 2026-10-28; this is not a legal opinion or a complete transitive redistribution clearance. Package versions may change when backend dependencies are installed because the full transitive set is not locked. Source-only publication, a built frontend, container images, and model distribution have different notice obligations.

## Frontend assets

`hero.png`, `react.svg`, `vite.svg`, `public/favicon.svg` and `public/icons.svg` came from the initial imported tree. Their independent provenance and licenses were not established. They are removed from the current tree; they remain accessible in existing Git history, so historical rights still require review. The previous landing-page terminal was an animation implemented in JSX, not a recording: it displayed an unimplemented CLI and an unverified duration. It has been replaced with explicitly labeled questions. The other background and interface animations are CSS and Framer Motion code inherited from the application; Framer Motion is a separately licensed dependency. Lucide React supplies the current UI icons, under its ISC license and included notices. The prior Google-hosted Inter and JetBrains Mono font references have been removed in favor of system font stacks; no font files are bundled by this project.

The frontend lockfile has 234 dependency entries: 209 installed on this Windows host and 25 not installed, mainly platform-specific entries. Of the installed entries, 203 had readable package-root license or notice files. Six did not: `@humanfs/types` (metadata Apache-2.0), `@rolldown/binding-win32-x64-msvc` (MIT), `dlv` (MIT), `esrecurse` (BSD-2-Clause), `imurmurhash` (MIT), and `natural-compare` (MIT). These metadata declarations are not substitutes for reviewing upstream license texts when those packages are distributed. The lockfile also declares `caniuse-lite` CC-BY-4.0, `lightningcss` MPL-2.0 and `minimatch` BlueOak-1.0.0; their terms and any applicable notices must be preserved when distributing them. They are build/development dependencies, not asserted here to appear in the application JavaScript.

The actual installed license files for React, React DOM, scheduler, Lucide React, Framer Motion, motion-dom and motion-utils are reproduced in [frontend/public/THIRD_PARTY_NOTICES.txt](../frontend/public/THIRD_PARTY_NOTICES.txt), which Vite copies into a production build. This is a selected runtime notice list, not a comprehensive audit of every tool or future dependency. Verify the bundle and regenerate notices when versions change; preserve all applicable notices in container or binary distributions.

## Backend dependencies

The current Python 3.11 environment contained 118 distributions. The audit read 109 distributions' `.dist-info` license/notice files; of the other nine, `onnxruntime` contains an in-package LICENSE and ThirdPartyNotices. The other eight lacked a distribution license file in the installed manifest: `flatbuffers`, `langchain-community`, `langchain-core`, `langchain-text-splitters`, `langsmith`, `opentelemetry-util-http`, `tokenizers` and `tqdm`. Their metadata indicates respectively Apache-2.0, MIT, MIT, MIT, MIT, Apache-2.0, an Apache classifier, and MPL-2.0 AND MIT. Confirm applicable upstream license files and notices before redistributing those packages. An absent metadata field or file is not evidence that a project is unlicensed.

The 11 distributions previously flagged for missing simple license metadata were individually inspected: `chroma-hnswlib` and `chromadb` include Apache-2.0 text; `colorama` includes BSD terms; `fastapi`, `markdown-it-py`, `marshmallow` and `mdurl` include MIT text; `networkx` includes BSD-3-Clause text; `packaging` includes Apache-2.0 and BSD alternative texts; `setuptools` includes MIT text and bundled vendor notices; `tokenizers` has an Apache classifier but no installed license file. Markdown-it-py includes an additional markdown-it license. Preserve those files in redistributed dependencies and inspect their actual wording for obligations.

The installed model packages and model weights are not included in this repository; model licenses and their distribution conditions need a separate review if shipped. ItsDangerous is a separate BSD-3-Clause evaluation checkout, not bundled wholesale. Repo-Sage attribution and the unresolved upstream license grant are covered by [release_licensing.md](release_licensing.md).
